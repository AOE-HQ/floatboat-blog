## Windows 上的 Raycast 缺口

如果你是从 Mac 刚切到 Windows 的用户——或者你是个 Windows 用户，只能眼巴巴看着 Mac 朋友用一个快捷键唤起 AI、管理文件、自动化工作流——你懂这种痛。Raycast 已成为 macOS 上效率启动器的黄金标准：快、可扩展、AI 加持、设计精美。

但在 Windows 上呢？选项一直……差强人意。

PowerToys Run 能用但过于简陋；Keypirinha 强大却偏开发者向；Wox 和 Flow Launcher 是可敬的开源努力，但缺了让 Raycast 显得像魔法的打磨、AI 集成和生态。

但问题是：**效率工具的版图已经变了。**在 2026 年，你真正需要的不是一款启动器——而是一个 AI 原生的工作区：它懂你的工作、记得你的偏好、还能自主执行多步任务。而**Floatboat**正是在这里登场的。

* * *

## Floatboat 是什么？

Floatboat 是第一个为一人公司、自由职业者和单人创业者打造的 AI Agent Workspace——**Windows 和 macOS 都能用**。它不是启动器，也不是聊天机器人。把它想成你的私人 AI 团队：就住在你桌面上，与你本地文件、浏览器和你已经在用的工具深度相连。

Raycast 给你的是带插件的命令面板；Floatboat 给你的是一个**全栈 AI 工作区**，随你的需求成长：从一个简单的 Agent Chat 起步，再扩展成分屏文件管理、浏览器自动化、拖拽式上下文流转，以及叫**Combo Skills**的可复用 AI 工作流。而当工作本身就是写作时，这个工作区还能再伸一层：[Flow Mode](/zh/blog/introducing-flow-mode) 把语音口述变成文档内的合写——启动工作的那块界面，也正是草稿写完的地方。

## 为什么 Floatboat 不只是「Windows 版 Raycast」

### 1\. 它学习你的工作方式

Raycast 很快，但它不学习。你配置它、装扩展、手动搭工作流。

Floatboat 的**Tacit Engine**走的是完全不同的路：它观察你在工作的方方面面如何编辑、如何决策、如何执行。久而久之，它捕捉到让你的业务运转起来的那套「操作直觉」——你的判断、你的标准、你偏好把事情做完的方式。不需要额外设置。

_你的工作方式是你业务最大的资产。Floatboat 就是这么对待它的。_

### 2\. Combo Skills：你的单人打法手册

不用在扩展商店里翻找单个插件，Floatboat 让你搭建**Combo Skills**——把「你怎么把活干完」固化下来的可复用 AI 工作流，以后类似的工作一出现，就重放这套打法。

  * **销售型创始人？**十分钟内把语音笔记变成一份可以直接见客户的 pitch 演示稿。

  * **内容创作者？**从零散的研究和粗糙草稿，一路到可发布成稿的文章——用你独特的声音。

  * **小企业主？**跑一次战略性合同审查，标出风险、给出反建议。

这些不是模板。它们是随你的上下文自适应、活生生的工作流。你还能在**ComboStore**里找到更多——一个由社区构建的即用技能市场。

### 3\. 上下文像水一样流动

Raycast 最好的功能之一是剪贴板历史和片段系统。Floatboat 把这个概念再抬高一层，做出**零摩擦的上下文流转**：

  * 把浏览器内容拖进文件夹，存成 Markdown

  * 把 Agent 回复直接拖进文件

  * 把本地文件拖进聊天——不用上传、不用复制粘贴

  * 内置浏览器让 Agent 可以浏览网页、收集信息、自动化网页任务

一切顺滑流动。你的上下文从不断裂。把浏览器交给 Agent，它就能自己跑完整个调研周期——[每周 TikTok Shop 调研自动化](/zh/blog/automate-tiktok-shop-research-fastmoss-floatboat) 就是这件事端到端的样子：浏览、收集、对比、交出一份简报，全程不需要人守着每一步。

### 4\. 原生桌面集成

Floatboat 不是一个假装成桌面工具的网络应用。它是一款**原生桌面应用**（Windows 10+ 与 macOS 13+），带深度系统集成：

  * 访问你电脑上的所有本地文件和软件

  * 直接把任务写进系统「提醒事项」

  * 唤起你的本地邮件客户端

  * 即时连接 3500+ 款工具

  * 和你现有的技术栈配合——Slack、Google Drive，不止于此

### 5\. 用户保护计划

这是任何启动器或 AI 工具都没给过的东西：**一份按结果付费的保障**。Floatboat 的 User Protection Program 是一个大胆的实验——如果 AI 确实没能交付，你可以申请受保护的额度返还，最高不超过你已付的金额。这是朝着「AI 按价值定价、而不只是按算力定价」迈出的一小步但很实在的一步。
