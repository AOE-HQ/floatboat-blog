**信息核对截至 2026 年 10 月 13 日。** GPT Image 2 仍可用，但 OpenAI 已在当前 API 文档中列出更新的 GPT Image 2.5 系列。本文保留 GPT Image 2 的制作方法，不把 4 月发布时的排名当成今天的结论。

GPT Image 2 可以帮助单人漫画创作者把文字分场变成可编辑的分镜候选，但不会自动保证角色连续、排字正确、人体可用或版权清晰。可靠的工作单位不是“生成一整章”，而是“一格画面 + 明确参考素材 + 验收标准 + 人工复核”。

## 官方能力能说明什么

OpenAI 的 [GPT Image 2 发布说明](https://openai.com/index/introducing-chatgpt-images-2-0/)提到文字渲染、编辑、版式、指令遵从与复杂视觉任务的改进；当前[图像生成文档](https://developers.openai.com/api/docs/guides/image-generation)说明了生成、编辑、参考图输入、质量、尺寸、格式与多轮修改。它们是能力边界，不是角色、服装、对白或场景跨整章不漂移的保证。

API 按 token 计费，总成本包含提示词、参考图输入与图像输出；带参考图的编辑还可能增加输入成本。不要使用固定“每格几美分”的旧估算，应以官方计算器和真实任务账单为准。

## 把整章拆成可控资产

### 1. 先锁定脚本

用表格记录页码、格号、景别、动作、对白、拟声词和连续性要求。每格都写清哪些元素必须保持、哪些允许变化。对白先保留为独立文字，不要让图像提示词成为唯一文稿。

### 2. 建角色、场景与道具设定页

为 recurring 角色准备正面、侧面、服装、配色、比例与禁止变化；场景和关键道具也单独留档。生成新格时复用已验收图片，不要只靠角色名维持身份。这套资产纪律同样适用于[分镜工作流](/zh/blog/gpt-image-2-storyboard-solo)。

### 3. 一次只生成一格

提示词写构图、镜头、动作、光线和气泡留白。先生成候选，选中一张后再做编辑。一次生成整页会把多个失败原因混在一起，也更难保住已经合格的画面。

### 4. 在外部工具排字

模型生成的文字只当草稿。把验收后的画面导入排版工具，再放置对白和拟声词，并保留可编辑文字层。这样才能分别处理拼写、翻译、字体许可、阅读顺序和印刷规范。

## 用同一张清单审每一格

逐项检查身份、手部、服装、道具、空间关系、阅读顺序、对白与出血安全区，再对照相邻格检查无理由变化。记录具体退回原因，比“看起来不对”更利于迭代。

先做短篇试刊，记录每格验收所需生成次数、编辑次数、排字时间、审校时间和总成本。若要换模型，用同一套素材与评分表；[三款图像工具的选型对比](/zh/blog/gpt-image-2-vs-midjourney-nano-banana-2)也应按这种方式读取，而不是寻找绝对冠军。

## 版权、披露与交付

不要直接模仿在世画家的签名风格，也不要假设生成结果天然可商用。交付前核对平台条款、客户合同、字体许可、参考图权利、当地披露规则和出版社 AI 政策。保存脚本、提示词、参考素材、候选、修改记录与最终排字，形成可追溯档案。

## 最小验收测试

先做六格短场景：两名角色、一个连续出现的道具、一次场景切换、目标语言对白和一个特写。只有经人工修正后仍通过连续性与排字检查，才值得扩展到整章。若失败，应先改参考素材或工具选择，而不是不断堆提示词形容词。[GPT-6 到来前的准备清单](/zh/blog/openai-gpt-6-one-person-company)也强调应保留可复用资产，而不是押注某个模型名称。
