**本文最初发布于 2026 年 4 月 17 日；信息核对截至 2026 年 10 月 13 日。** DeepSeek 使用滚动别名与分时价格，估算生产成本前应重新核对官方目录。

DeepSeek V4 API 可以成为文档处理、编程 Agent 和重复后台工作的低成本候选，但最低 token 单价不等于预算。单人经营者还要知道：请求实际由哪个模型处理、是否落在峰时、提示词有多少命中缓存，以及一个完成任务会产生多少次重试和工具循环。

## 当前模型 ID

DeepSeek 的[模型与价格文档](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)列出两个名称：

- `deepseek-flash`：DeepSeek-V4.1-Flash，支持文本与图像输入。
- `deepseek-v4-pro`：目录显示为 DeepSeek-V4-Pro-0813。

官方为两者列出 1M 上下文、最高 384K 输出、思考/非思考模式、工具调用、JSON 输出、Responses API 与 Anthropic 格式。不过，[V4.1 Flash 发布说明](https://api-docs.deepseek.com/zh-cn/news/news260910/)称，从 9 月 14 日起，在 V4.1-Pro 上线前，`deepseek-v4-pro` 请求会路由到 V4.1 Flash。模型别名会移动，应用若依赖固定检查点，必须单独确认。

## 官方 token 价格

当前每百万 token 的公开价格如下：

| 模型 | 缓存命中输入 闲/峰 | 缓存未命中输入 闲/峰 | 输出 闲/峰 |
|---|---:|---:|---:|
| V4.1 Flash | $0.003 / $0.006 | $0.15 / $0.30 | $0.60 / $1.20 |
| V4 Pro | $0.022 / $0.044 | $0.66 / $1.32 | $1.98 / $3.96 |

峰时为工作日 UTC 01:00–04:00 与 06:00–10:00，中国法定节假日除外；其他时段按闲时计算。这只是 API token 费用，不代表流程总成本。网页搜索、外部工具、存储、队列、监控和失败运行还会额外计费。

## 按“验收通过的任务”算成本

每条流程都应记录缓存未命中输入、缓存输入、输出、模型调用次数、工具费用、重试次数，以及结果是否被人工接受。计算式为：

`每个验收任务成本 = 所有运行费用 / 被接受的输出数`

这样能避免一种错觉：某模型单 token 很便宜，却输出更多、循环更多，或产出的工作必须重跑。应使用一个月里具有代表性的任务，而不是单条提示。与其他供应商比较时也用同一口径。

当政策、schema、参考材料或仓库说明等稳定前缀反复出现时，缓存价值最大。不要为了命中缓存故意填充提示词；把稳定材料独立出来，测量真实命中率，并测试缓存失效或未命中时的成本。

## 适合单人经营者的安全试点

先选分类、草稿或只读分析等可回滚工作。设置每周硬预算与单任务最大调用次数。在发送消息、覆盖文件或修改外部记录前强制人工审核。日志至少记录模型别名、时间、思考模式、token、工具调用和最终处理结果。

扩量前准备一组验收用例：

1. 普通输入；
2. 长上下文；
3. 格式错误；
4. 证据缺失；
5. 重复事件或重试；
6. 必须停下来请求批准的操作。

编程场景可使用 DeepSeek 官方提供的 Claude Code 与 Codex 接入方式，但切换端点不会消除框架的安全责任，详见 [DeepSeek Agent 与 Claude Code 对比](/zh/blog/deepseek-agent-vs-claude-code)。当前 Flash 检查点与旧别名状态见 [DeepSeek V4.1 Flash](/zh/blog/deepseek-v4-1-flash)。

## 什么情况下值得用

如果工作量大、结果可审核，并能接受供应商路由变化，它值得进入试点。如果监管要求固定检查点、跨时区延迟必须恒定，或核心集成未受支持，就应谨慎。“便宜”足以换来一次受控测试，但不足以直接批准生产上线。
