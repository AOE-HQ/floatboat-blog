## TL;DR

- **文本转幻灯片工具把纯文本大纲变成演示文稿：每个标题或分隔符就是一页，文件保持可版本化的文本，一条命令导出 PDF、HTML 或 PowerPoint。** 截至 2026 年，支撑这套工作流的是 Marp 和 Pandoc。
- 收益与 [markdown 简历](/zh/blog/markdown-resume)是同一个单一源模型：内容是文件，成片是构建产物，版式在导出时才发生。
- 诚实的代价：放弃拖拽式排版。文本驱动的幻灯片干净、一致，但不做艺术指导。
- 优势场景：技术分享、内部汇报、以及一切改到最后一分钟的材料。劣势场景：需要精确图片排布的视觉叙事。
- 与 AI 协作是被低估的优势——agent 天然会写和重组幻灯片大纲，因为大纲就是 Markdown。

## 1. 幻灯片文件的问题

传统幻灯片文件把内容和版式混在一个二进制包里，任何结构性调整都是手工活：调整三个章节的顺序，就意味着拖拽页面、重排每个标题。幻灯片工具的版本历史从薄弱到没有，评审一份片子意味着打开那个应用。

文本驱动的幻灯片把模型倒了过来。演示文稿是一个 Markdown 文件，页面由分隔符（Marp 的 `---`）或标题切分。文件可以干净地 diff、干净地版本化，通过一个应用统一主题的工具渲染。你写论证，工具管排版。

这是 docs-as-code 的思路套在[另一种产物](/zh/blog/what-is-markdown)上——和文档站一样，源文件才是资产，导出不是。

## 2. Marp——为幻灯片而生的 Markdown

Marp（Markdown Presentation Ecosystem）就是为这套工作流而造。一个 `---` 分隔符开新页；每页的 front matter 控制版式（`paginate: true`、双栏指令）；支持图片，[数学公式经 LaTeX 记号渲染](/zh/blog/markdown-math-latex)；Marp CLI 导出 PDF、PowerPoint（.pptx）和 HTML——HTML 版在任何浏览器里实时渲染，顺手兼任演示视图。

最小的一份片子：

```markdown
---
marp: true
theme: default
---

# 论点

一页一个想法，就像一个文件一件事。

---

## 证据

- 幻灯片文本可以在 pull request 里评审
- 主题是一行配置
```

[Marp 文档](https://marpit.marp.eu/)覆盖了指令体系；生态里还有带实时预览的 VS Code 扩展——改文本，看页面。截至 2026 年，它仍然是门槛最低的入口。

## 3. Pandoc——幻灯片只是又一种导出

如果你已经在跑单一源工作流——简历、文档、报告——Pandoc 把幻灯片当作又一个构建目标：`pandoc talk.md -o talk.pptx`，或经 Beamer 模板出 PDF。标题层级映射到页面和子页面边界。

代价也是 [Pandoc 转换路径一贯的代价](/zh/blog/how-to-convert-markdown-to-pdf)：更强的控制和模板能力，换来的配置和模板调试。已经在维护 Pandoc 模板的团队做幻灯片几乎免费；其他人从 Marp 起步。

## 4. 文本幻灯片做不好什么

对天花板诚实：重图片、重设计的片子——市场 keynote、大会视觉、任何依赖精确品牌版式的材料——是错误的用例。文本驱动的工具应用主题；它们不做艺术指导。如果某一页的信息依赖一张图片精确占据画布的某个百分比、文字环绕其侧，那一页（或者整份）请用设计工具。

还有演示习惯的调整：并非每种导出格式都有与 PowerPoint 对等的演讲者备注视图，围绕 .pptx 建立的排练流程也无法照搬。提交前先确认导出目标支持你的演示配置——截至 2026 年，PDF 和 HTML 是最稳的导出；.pptx 输出真实存在但比原生 PowerPoint 简朴。

## 5. 文本幻灯片的决定性优势场景

技术分享和内部汇报是甜点位，原因有三条且相互叠加。片子像代码一样被评审——同事可以在 pull request 里对某一页的文字写评论。临时改动是文本编辑而不是排版手术——前一晚 23:50 修一个数字是安全的。AI agent 可以原生起草、重组、收紧幻灯片大纲，因为大纲就是 Markdown——[Mermaid 图表](/zh/blog/mermaid-diagrams-in-markdown)受益的是同一个协作循环。

所有这些背后是同一个模式：当价值在论证里，就把论证留在文本里，让工具去渲染。

## 6. 结语

Markdown 转幻灯片不是要取代设计师手里的 PowerPoint。它移除的是「内容即文字」的那类幻灯片——技术分享、状态汇报、内部评审——的排版税，并让这些片子进入你其余文本工作流所在的同一个可版本化、可评审、可与 AI 协作的世界。

拿这个月你要讲的最小的一份片子试一下：写大纲，渲染，然后注意时间都花在了哪。
